# Data

Only synthetic patient data and reviewed public guideline inputs may be used in
this directory. See the
[development safety and data policy](../docs/SAFETY_AND_DATA_POLICY.md).

- `synthetic/` is reserved for small, reviewed synthetic fixtures.
- `guidelines/` is reserved for guideline source metadata and development
  ingestion inputs.
- `generated/` is ignored and reserved for reproducible generated artifacts.
